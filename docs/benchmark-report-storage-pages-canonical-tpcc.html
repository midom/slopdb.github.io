Canonical TPC-C storage evidence

All ten supported engine/page cases freshly replayed one frozen SQL file and passed complete typed fingerprints after close/reopen and after maintenance. The nine tables contain 10,518,120 rows and exactly 713,759,360 logical payload bytes in every case. The canonical file has 321,378,587 bytes and SHA256 8772c9bfcb2672d1b18bfb6aa98059489d26962083c94568f089be211eccd543. Every supported case executes the same 46,242 SQL statements.
