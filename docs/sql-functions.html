Same name, different rules

Choose the family that matches your session. Native LENGTH counts text characters; MySQL LENGTH counts bytes. MySQL CONCAT returns NULL if any argument is NULL; PostgreSQL CONCAT skips NULL arguments. MySQL LOG(value) is natural log, while PostgreSQL LOG(value) is base 10. Native RANDOM remains an integer in PostgreSQL mode. CHANGES and LAST_INSERT_ROWID currently return zero; PG_GET_SERIAL_SEQUENCE returns NULL.

Core and shared JSON functions remain available alongside dialect-specific functions, subject to overrides. This is a reference to SlopDB’s implementation, not a promise of complete upstream database compatibility. Missing functions, unsupported argument shapes, or invalid input can fail rather than silently emulate a different result.
