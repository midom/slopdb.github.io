MySQL-style functions

Function inventory verified against the supplied SlopDB source checkout adbd3a6. Entries document implemented behavior, including compatibility placeholders and restrictions.

← Search all SQL functions · 179 documented names/forms in this family.

This reference covers MySQL-style scalar functions and special call syntax implemented by SlopDB. Many also work in native expressions; connection identity, advisory locks, and connection result state require the relevant session context. MySQL protocol sessions enable MySQL-specific coercion and overrides. See the compatibility guide and server setup.

Shared functions and overrides

Core conditional, string, date, aggregate, and JSON functions remain available. In MySQL mode, LENGTH counts bytes, HEX keeps native textual-byte conversion for numeric inputs, ROUND supports negative positions and exact/approximate tie rules, and ABS uses MySQL numeric coercion. Explicit CONVERT_TZ calls also convert between supported fixed offsets and available host IANA zones. See core functions, shared JSON, and aggregates.

Coercion and bounds

MySQL numeric helpers generally accept a leading numeric prefix in strings. TEXT positions count Unicode code points; BLOB operations count bytes. Expanded strings, padding, formatting, and decompression are checked against the query memory budget. Wrong argument counts fail even on empty input. NULL handling and domain errors are function-specific.

Temporal values use TEXT and the session timezone is UTC. The implementation includes month-end clamping, leap years, all eight WEEK modes, and signed durations up to the MySQL 838-hour range. Date names are English. It does not implement every MySQL sql_mode, warning, collation, timezone conversion, or temporal coercion.

Regex flags and boundaries

Supported match flags include i (case-insensitive), c (case-sensitive), m (multiline), n (dot matches newline), and u (supported Unix-line behavior). The u flag is accepted while RE2 retains its line-ending semantics. The engine uses RE2 rather than ICU; unsupported pattern constructs fail. Check the compatibility guide before relying on upstream-specific regex behavior.
