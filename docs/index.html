SLOPDB / DOCUMENTATION

A little guidance.
A lot of possibilities.

SlopDB is an embedded SQL database written in Go. Start with a local database directory, embed it in an application, or enable a SQL protocol listener.

These guides are rendered directly from the project’s documentation. They describe supported behavior, operational settings, and compatibility limits.

Start small

Build from the repository root with Go 1.22.2 or newer:

git clone https://github.com/midom/slopdb.git
cd slopdb
go build -o slopdb .
./slopdb ./example-db

Performance with context

The project includes regression tests and SQL reference fixtures, plus TPC-C-inspired and TPC-H development workloads. These are development benchmarks, not certified TPC scores. Compare runs using matching datasets, concurrency, execution modes, and durability settings.
