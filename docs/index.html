SLOPDB / DOCUMENTATION

A little guidance.
A lot of possibilities.

SlopDB is an embedded SQL database written in Go. Start with a local database directory, embed it in an application, or enable a SQL protocol listener.

These guides are rendered directly from the project’s documentation. They describe supported behavior, operational settings, and compatibility limits.

Start small

Build from the repository root with Go 1.22.2 or newer:

git clone https://github.com/midom/slopdb.git
cd slopdb
go build -o slopdb .
./slopdb ./example-db

Recent additions

  • Embedded database/sql driver: path-based engine sharing, isolated pooled sessions, streaming rows, and caller-owned connectors.
  • MySQL and PostgreSQL listeners can serve one physical database in the same process, with independent session dialects.
  • Shared catalog relations and live activity views expose session-visible metadata, query text, identities, and real lock waits.
  • Persisted full-text analyzers configure tokenization, normalization, stopwords, and ranking across frontends.
  • PostgreSQL compatibility updates include snapshot-conflict behavior for REPEATABLE READ, transactional temporary tables, one-statement COPY imports, and additional functions.
  • Session variables, live inspection, and atomic bulk loading include typed user variables, SHOW RAFT STATUS, SHOW LSM STATUS, and LOAD DATA LOCAL INFILE.
  • WordPress and MediaWiki guides record the tested application workflows and remaining compatibility boundaries.
